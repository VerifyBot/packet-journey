מעבדת שבירה :: שרת ולקוח
=========================

מה יש כאן
server.py   השרת. מחכה שמישהו יתחבר ועונה לו.
client.py   הלקוח. מתחבר לשרת, שולח שם, ומקבל תשובה.

איך מריצים
צריך שני חלונות של cmd, שניהם פתוחים בתיקייה הזאת.
כדי לפתוח cmd בתיקייה: תיכנסו אליה בסייר הקבצים, תלחצו על שורת הכתובת למעלה,
תמחקו מה שכתוב שם, תכתבו cmd ואנטר.

חלון ראשון, ורק אחר כך השני:

    python server.py

חלון שני:

    python client.py

הלקוח יבקש שם. תכתבו משהו ואנטר. התשובה מהשרת תודפס אצלכם.
השרת נשאר פתוח וממשיך לחכות ללקוח הבא. אפשר להריץ שוב את client.py כמה פעמים שבא לכם.

לעצור תוכנית: Ctrl+C בחלון שלה.

כשמשהו לא עובד
אם כתוב שהפקודה python לא מוכרת, תנסו py במקום python.
אם כתוב שהפורט תפוס, יש לכם עוד חלון עם שרת שרץ. תסגרו אותו,
או תשנו את המספר 1234 בשני הקבצים לאותו מספר אחר, למשל 1235.
אם הלקוח נתקע ולא קורה כלום, זה בסדר. זה חלק מהניסויים. Ctrl+C ותמשיכו.

הניסוי בין שני מחשבים
אחד מכם מריץ server.py, השני מריץ client.py, ומדברים מהמחשב שלו למחשב שלך.
תעשו את זה על נקודה חמה מהטלפון, לא על הרשת של בית הספר.
ברשתות של מוסדות כמעט תמיד דולק בידוד לקוחות שחוסם מכשירים מלדבר אחד עם השני,
והחיבור ייפול גם אם הקוד שלכם מושלם.
1. אחד מכם מדליק נקודה חמה, ושני המחשבים מתחברים אליה.
2. במחשב של השרת, בחלון cmd, מריצים

    ipconfig

מחפשים את השורה IPv4 Address, משהו בסגנון 192.168.43.17, וזאת הכתובת שלו.
במק או בלינוקס משתמשים ב- ifconfig במקום.
3. במחשב של הלקוח, פותחים את client.py, ומחליפים את 127.0.0.1 בכתובת הזאת.

חומת אש
בפעם הראשונה שמריצים server.py ווינדוס יקפיץ חלון של Windows Defender Firewall
שמבקש הרשאה. צריך לסמן Private networks וללחוץ Allow access.
אם לחצתם Cancel בטעות, או שהחלון בכלל לא קפץ והחיבור מהמחשב השני נתקע ואז נופל,
זאת חומת האש חוסמת. לכו ל- Windows Defender Firewall, ואז
Allow an app through firewall, ותאשרו שם את Python ברשת Private.
מהמחשב עצמו, עם 127.0.0.1, זה תמיד יעבוד גם בלי זה.
