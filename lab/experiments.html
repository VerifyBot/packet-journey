מעבדת שבירה

לפני שמתחילים

קודם כל צריך שיהיה לכם קוד שעובד. תורידו את שני הקבצים לאותה תיקייה, ותריצו אותם פעם אחת בדיוק כמו שהם.

  1. תשימו את שני הקבצים באותה תיקייה.
  2. תפתחו שם cmd. בסייר הקבצים לוחצים על שורת הכתובת למעלה, מוחקים מה שכתוב, כותבים cmd ואנטר.
  3. בחלון הראשון מריצים python server.py‏.
  4. פותחים חלון שני באותה תיקייה ומריצים python client.py‏.
  5. תכתבו שם ואנטר. חזר אליכם Hello עם השם שלכם? מעולה, אתם בבית.

רק אחרי שזה עבד מתחילים מניסוי 1. כל שבעת הניסויים מניחים שהבסיס רץ אצלכם. אחרת תרדפו אחרי טעות הקלדה שלכם במקום אחרי הדבר האמיתי.

server.py
import socket IP = "0.0.0.0" # 0.0.0.0 = תקשיב לכל כרטיסי הרשת של המחשב PORT = 1234 server = socket.socket() server.bind((IP, PORT)) server.listen() print("Server listening on port", PORT) while True: # accept נתקע כאן עד שלקוח מתחבר client, addr = server.accept() print("Connected:", addr) while True: data = client.recv(1024) # נתקע כאן עד שמגיעים בייטים if not data: # b"" = הצד השני סגר break name = data.decode() # בייטים -> טקסט print("Got:", name) client.send(("Hello " + name).encode()) # טקסט -> בייטים client.close() print("Client closed. Waiting for the next one.")
client.py
import socket SERVER_IP = "127.0.0.1" # 127.0.0.1 = המחשב הזה עצמו SERVER_PORT = 1234 client = socket.socket() client.connect((SERVER_IP, SERVER_PORT)) # השרת חייב כבר לרוץ print("Connected to", SERVER_IP, SERVER_PORT) msg = input("Your name: ") client.send(msg.encode()) # טקסט -> בייטים data = client.recv(1024) # נתקע כאן עד שמגיעה תשובה print("Server said:", data.decode()) client.close()
  1. קודם מנחשים, רק אחר כך מריצים. תכתבו את הניחוש לפני שאתם נוגעים במקלדת. ניחשתם לא נכון? מעולה, זה שווה בדיוק כמו לנחש נכון.
  2. אחרי כל ניסוי תחזירו את הקוד למה שהיה. אחרת הניסוי הבא ישקר לכם.
  3. שני חלונות cmd פתוחים כל הזמן: שרת בראשון, לקוח בשני. ותמיד, אבל תמיד, מריצים קודם את השרת.
  4. תוכנית שנתקעת נסגרת עם Ctrl+C‏. שימו לב: תקוע זה לא קלקול, זה תוצאה.
  5. שגיאה אדומה בקונסולה זאת התשובה שלכם. תקראו את השורה האחרונה שלה. כל הבלגן מעליה הרבה פחות מעניין.
  6. אפשר להיעזר בחבר, באינטרנט וב-AI. רק תוודאו עם עצמכם שבאמת הבנתם מה קרה, זה בשבילכם.

לצאת מהמחשב שלכם

מה עושים

רשות, וצריך שני מחשבים. תעשו אותו על נקודה חמה מהפלאפון, לא על הרשת של בית הספר. למה? כי ברשתות של מוסדות כמעט תמיד דולק בידוד לקוחות, שחוסם מכשירים על אותה רשת מלדבר אחד עם השני. הקוד שלכם יהיה מושלם וזה פשוט לא יתחבר. בנקודה חמה אין את החסימה הזאת.

  1. אחד מכם מדליק נקודה חמה בפלאפון, ושני המחשבים מתחברים אליה.
  2. במחשב שמריץ את השרת פותחים cmd ומריצים ipconfig‏. מחפשים את השורה IPv4 Address‏. במק או בלינוקס משתמשים ב-ifconfig‏ במקום.
  3. אותו מחשב מריץ python server.py‏ ומשאיר את החלון פתוח.
  4. במחשב השני משנים את השורה:
לפניSERVER_IP = "127.0.0.1"
אחריSERVER_IP = "192.168.43.17"

עם הכתובת שקיבלתם במקום זאת שכתובה פה, ואז מריצים שם python client.py‏ ושולחים שם. אחר כך מחליפים תפקידים.
